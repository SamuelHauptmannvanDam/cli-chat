❯ the installer

One command sets up cli-chat in every coding CLI on your machine. It registers the cli-chat server with each CLI it finds — nothing else lands on your disk; the server itself runs via npx whenever your CLI starts it.

macOS · Linux · Windows (WSL) 
curl -fsSL https://cli-chat.dev/install | sh

Prefer to look before you leap? Read the script — it's about a hundred lines of plain sh. Safe to re-run any time: already-registered CLIs are reported and left alone, so run it again after you install a new coding CLI.

## per OS

macOS

Open Terminal, paste the command. Needs Node 22+ — brew install node or nodejs.org if you don't have it.

Linux

Any shell. Needs Node 22+ — distro packages are often older, so check node -v; nodejs.org has current builds.

Windows

The installer is a POSIX shell script: run it inside WSL — where the coding CLIs live anyway — or Git Bash. Plain PowerShell isn't supported yet.

downloaded the file?

Same thing without the pipe: sh install from wherever you saved it.

## what it does — and doesn't

checks

Node 22+ is present — otherwise it tells you where to get it and stops. Nothing half-installed.

registers

Claude Code, Codex, Copilot and Gemini through their own mcp add commands; Cursor by merging ~/.cursor/mcp.json. Each CLI it can't find is simply skipped.

never

Downloads binaries, touches your PATH, or starts anything. The only writes are the CLIs' own MCP config entries.

any other MCP client

Register a stdio server by hand: command npx, args ["-y", "cli-chat-mcp@latest"].

## after it runs

Restart your CLI and allow the new cli-chat server when it asks. Then just write someone — write sam: hey. Setup happens in that first conversation: it asks for your email, sends a magic link, and your account (new or existing) lands on this machine — identity, contacts and history included.
