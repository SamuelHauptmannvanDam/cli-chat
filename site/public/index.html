## 01 · install

claude mcp add cli-chat --scope user -- npx -y cli-chat-mcp@latest

Then restart your CLI, allow the new cli-chat server when it asks, and just write someone. Setup happens on the way, like this. Needs Node 22+.

Not ready for autopilot? "chat" reads your inbox to you, "draft chat" proposes replies you approve — say "auto chat" when you trust it.
